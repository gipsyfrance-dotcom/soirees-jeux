# Soirées jeux – Noisy & alentours

Page d'inscription aux soirées jeux : https://gipsyfrance-dotcom.github.io/soirees-jeux/

- `index.html` : la page (liste des soirées, inscription, espace hôtes).
- Les données sont dans le Google Sheet ; la page les lit via l'API Apps Script (`API_URL` dans `index.html`).
- Pour mettre à jour la page : modifier `index.html` puis enregistrer (commit) — c'est en ligne environ une minute après.
